# Jet flow — dog trimmer homepage (Shopify)

Files applied to the Shopify theme **"Jet flow — Trimmer forside (Claude)"**
(a duplicate of the live Impulse theme) on jetflow.dk.

- `templates/index.json` — new product-focused homepage selling the
  Oneisall Pelspleje Støvsuger Sæt: hero, USP icons, featured-product buy box,
  two story sections, FAQ and a closing CTA (all in Danish).
- `config/settings_data.json` — header announcements localized to Danish
  (replaced the English "Free shipping over $100" placeholders).

To go live: Shopify admin → Online Store → Themes → preview the duplicate
theme and click **Publish**.
